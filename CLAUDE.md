# CLAUDE.md – Stochastic Simulation (02443)

## Working directory
All solution files go inside `exercises/dayX/mathilde/` for exercises, and `project1/mathilde/` or `project2/mathilde/` for projects. Never write outside the `mathilde/` subfolder.

## File structure per day
```
exercises/
  day1/mathilde/   ← your solutions here
  day2/mathilde/
  ...
project1/mathilde/
project2/mathilde/
```

## Coding standards
- Write clean, readable Python as a top-level student would: correct, concise, well-named variables.
- Use the minimum code needed to solve the problem — no boilerplate, no unnecessary abstractions.
- Follow the exercise instructions precisely before adding anything extra.
- Use `utils/plotting.py` for all plots.
- One file per exercise (e.g. `ex1.py`, `ex2.py`) unless the exercise says otherwise.

## Style
- No multi-line docstrings. A single short comment only when the intent is non-obvious.
- Prefer `numpy`/`scipy` built-ins over reimplementing standard algorithms unless the exercise explicitly asks you to implement them.
- Keep solutions self-contained — import only what is needed.
